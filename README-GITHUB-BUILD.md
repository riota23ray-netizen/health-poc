# HealthPoC — календарь активности и демо-соревнования

## Сборка через GitHub Actions без собственного Mac

1. Создайте пустой репозиторий на GitHub.
2. Загрузите **содержимое этой папки** в корень репозитория (файлы `HealthPoC.xcodeproj`, `HealthPoC/` и `.github/` должны быть на верхнем уровне).
3. Откройте вкладку **Actions**. Если GitHub предложит включить Actions, подтвердите.
4. Выберите **Build iOS app** → **Run workflow**.
5. После завершения откройте запуск workflow и скачайте артефакт `HealthPoC-unsigned-ipa`.
6. Этот IPA **не подписан сертификатом Apple**. Подпишите его на Windows с помощью Sideloadly/AltStore и своим Apple ID. Не загружайте сертификаты или приватные ключи в репозиторий.

## Что реализовано

- Стартовый экран позволяет выбрать Apple Watch или Xiaomi Mi Band 8; разрешения и чтение данных идут через Apple Health.
- Существующее подключение к Apple Health сохранено.
- Календарь показывает дневные данные HealthKit: активные калории, минуты упражнений и минуты стояния, если Apple Health содержит эти данные и доступ к ним разрешён.
- Будущие дни остаются серыми; кольца показывают долю от демонстрационных целей: 500 активных ккал, 30 минут упражнений и 12 часов стояния. Цели пока фиксированные.
- Экран соревнования — демонстрационный, с выбором устройства/режима и счётом 1:2. Реального подключения соперника, Xiaomi/Mi Fitness и синхронизации между телефонами пока нет.

## Примечания

- Первичная сборка требует включённой в проект возможности HealthKit; её уже содержит исходный проект.
- Для чтения данных iOS покажет системное окно доступа. HealthKit не сообщает приложению напрямую, отказал ли пользователь в доступе к конкретному типу данных; пустые кольца могут означать отсутствие записей или отсутствие разрешения.
- Workflow собирает **неподписанный** IPA для дальнейшей подписи. Сам по себе артефакт из GitHub Actions не устанавливается на iPhone, пока не будет подписан.
