# Health PoC — проверка: Apple Watch → HealthKit → iPhone

Минимальное приложение из трёх экранов. Задача одна: убедиться, что данные с часов читаются правильно (п. 17 ТЗ).

## Что где лежит

| Файл | Что делает |
|---|---|
| `HealthPoCApp.swift` | Точка входа. Переключает экраны: загрузка → подключение → данные |
| `LoadingView.swift` | **Экран 1.** Зелёный экран с логотипом и индикатором |
| `ConnectView.swift` | **Экран 2.** Объясняет, что читаем, кнопка «Подключить Apple Watch» |
| `DashboardView.swift` | **Экран 3.** Шаги, калории, тренировки и список источников |
| `ActivityData.swift` | Общая модель данных. Не знает про Apple — сюда же потом придёт Samsung |
| `AppleHealthProvider.swift` | Всё, что связано с Apple: разрешения и чтение данных |
| `HealthPoC.entitlements` | Разрешение на HealthKit |

## Что понадобится

- iPhone (iOS 16 или новее) и сопряжённые с ним Apple Watch
- Обычный бесплатный Apple ID
- Путь А: Mac знакомого с Xcode. Путь Б: компьютер на Windows и аккаунт GitHub

---

## Путь А — через Mac знакомого (надёжнее)

1. Скопировать папку `HealthPoC` на Mac, открыть `HealthPoC.xcodeproj` в Xcode.
2. Xcode → Settings → Accounts → «+» → войти своим Apple ID.
3. Слева нажать на проект HealthPoC → вкладка **Signing & Capabilities** → в поле **Team** выбрать свой Apple ID («Personal Team»).
4. Если Xcode ругается на Bundle Identifier — поменять `ru.raz.healthpoc` на любой свой, например `ru.raz.healthpoc2`.
5. Подключить iPhone кабелем, выбрать его вверху окна, нажать ▶︎ (Run).
6. На iPhone при первом запуске: **Настройки → Конфиденциальность и безопасность → Режим разработчика** → включить, перезагрузить.
7. **Настройки → Основные → VPN и управление устройством** → доверять своему Apple ID.

Приложение работает 7 дней, потом повторить шаг 5.

## Путь Б — без Mac (GitHub + Sideloadly)

1. Создать аккаунт на github.com, создать новый репозиторий, загрузить туда **всё содержимое** папки `HealthPoC` (включая скрытую папку `.github`).
2. Вкладка **Actions** → «Build iOS app» → **Run workflow**. Через 3–5 минут сборка закончится.
3. Открыть завершённую сборку → внизу **Artifacts** → скачать `HealthPoC-ipa` (внутри файл `HealthPoC.ipa`).
4. На Windows установить **iTunes с сайта Apple** (не из Microsoft Store) и **Sideloadly** (sideloadly.io).
5. Подключить iPhone кабелем, в Sideloadly выбрать `HealthPoC.ipa`, ввести Apple ID, нажать Start.
6. На iPhone — шаги 6 и 7 из пути А.

⚠️ Риск пути Б: при такой установке HealthKit может не заработать. Признак — приложение вылетает при нажатии «Подключить» или окно разрешений не появляется. Тогда остаётся путь А.

## Как проверить, что всё правильно

| # | Проверка | Что должно быть |
|---|---|---|
| 1 | Сравнить «Всего» по шагам и калориям с приложениями «Здоровье» / «Фитнес» | Совпадает (может отличаться на пару шагов, если часы не успели синхронизироваться) |
| 2 | Посмотреть «Источники данных» | Видны отдельно часы ⌚ и телефон 📱 |
| 3 | Прогулка с часами и телефоном, потом «Обновить» | «Всего» не удваивается |
| 4 | В «Здоровье» → Шаги → «Добавить данные» → 5000 | «Всего» и «Вручную» выросли на 5000, «С часов» — нет |
| 5 | Прогулка 5–10 минут, потом потянуть экран вниз | Цифры выросли |

Если проверки 1–5 пройдены — техническая основа проекта работает.

### Почему «С часов» может быть меньше, чем «Всего»
Если часть дня телефон был в кармане без часов, эти шаги посчитал телефон. Apple складывает данные с умом, а колонка «С часов» показывает только то, что засчиталось бы в соревновании. Это нормально и как раз то, что нужно проверить.
